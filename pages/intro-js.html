Introducción JavaScript

¿Qué es JavaScript?

Leer explicación

JavaScript es un lenguaje de programación interpretado y orientado a objetos que se ejecuta en el navegador (también en servidores con Node.js). Sirve para hacer sitios web interactivos: formularios, animaciones, eventos, etc.

Variables y Tipos de Datos

Leer explicación

En JavaScript las variables sirven para guardar información. Se pueden declarar con let (puede cambiar), const (no cambia) o var (antiguo y desaconsejado). Los tipos de datos se dividen en primitivos y compuestos. 

            
// Declaración de variables
let nombre = "Juan";
const edad = 30;
var ciudad = "Lima"; 

// Tipos de datos primitivos
let saludo = "Hola";       // String
let edad2 = 25;            // Number
let esEstudiante = true;   // Boolean
let variableNoDefinida;    // Undefined
let valorNulo = null;      // Null

// Tipos de datos compuestos
let persona = { nombre: "Ana" };   // Object
let numeros = [1, 2, 3];           // Array

// Mostrar por consola
console.log("String:", saludo);
console.log("Number:", edad2);
console.log("Boolean:", esEstudiante);
console.log("Undefined:", variableNoDefinida);
console.log("Null:", valorNulo);
console.log("Object:", persona);
console.log("Array:", numeros);

Bucles

Leer explicación

  console.log("Iteración:", i);

do {
  console.log("Número:", numero);
  numero++;
} while (numero < 2);

DOM desde Cero: Fundamentos y Práctica

¿Qué es el Document Object Model (DOM)?

Leer explicación

El DOM (Document Object Model) en JavaScript es una interfaz de programación que representa la estructura de un documento HTML como un árbol de objetos. Este modelo permite a los desarrolladores acceder, modificar y manipular los elementos de una página web de forma dinámica usando JavaScript.

¿Cómo funciona el DOM?

Cada etiqueta HTML se convierte en un nodo dentro del árbol DOM.
El nodo raíz es <html>, que contiene hijos como <head> y <body>, y estos a su vez tienen sus propios hijos.
JavaScript puede recorrer este árbol, seleccionar elementos, cambiar atributos, modificar estilos, insertar o eliminar contenido, y reaccionar a eventos del usuario.

¿Qué se puede hacer con el DOM en JS?

Algunas operaciones comunes con el DOM incluyen:

  • Seleccionar elementos: document.getElementById(), querySelector()
  • Modificar contenido: element.textContent, element.innerHTML
  • Cambiar estilos: element.style.color = "red"
  • Agregar o eliminar elementos: document.createElement(), element.remove()
  • Escuchar eventos: element.addEventListener("click", handler)

Nodos, Elementos y Selectores

Leer explicación

Nodos, Elementos y Selectores son conceptos clave para entender y manipular la estructura de una página web (DOM) usando JavaScript.

  • Nodo: cualquier unidad del DOM, puede ser una etiqueta, texto o comentario.
  • Tipos de nodos en el DOM:
    1. Nodo de documento: representa todo el documento HTML → document
    2. Nodos de elementos: cada etiqueta HTML es un nodo de tipo elemento → <div>, <h1>, <p>, <a>, etc.
    3. Nodos de texto: el contenido dentro de una etiqueta (incluso espacios y saltos de línea) → "Hola Mundo" en <p>Hola Mundo</p>
    4. Nodos de atributo (menos usados directamente): como class, id, src, etc. → <img src="imagen.jpg"> → src es un nodo de atributo
    5. Nodos de comentarios: comentarios en el HTML → <!-- Esto es un comentario -->
    6. Nodos de espacios vacíos: espacios o saltos de línea que también se interpretan como nodos
  • Elemento: nodo que representa una etiqueta HTML visible, como <div> o <p>.
  • Selector: método para buscar elementos en el DOM usando sintaxis CSS, como h1, .clase o #id.

Estilos y Variables CSS

Los estilos en línea se aplican directamente dentro del atributo style del elemento HTML. Los estilos computados son el resultado final tras combinar estilos en línea, hojas CSS y herencias. Las variables CSS (también llamadas custom properties) permiten definir valores reutilizables y dinámicos. 

            
// 📌 ESTILOS EN LÍNEA Y COMPUTADOS

console.log($linkDOM.style);
console.log($linkDOM.getAttribute("style"));

// Acceder a propiedades específicas (en línea)
console.log($linkDOM.style.backgroundColor);
console.log($linkDOM.style.color);

// getComputedStyle => Permite ver TODOS los estilos finales aplicados
console.log(window.getComputedStyle($linkDOM));
console.log(getComputedStyle($linkDOM).getPropertyValue("color"));

// ✅ Establecer estilos directamente desde JavaScript
$linkDOM.style.setProperty("text-decoration", "none");
$linkDOM.style.setProperty("display", "block");

$linkDOM.style.marginLeft = "auto";
$linkDOM.style.marginRight = "auto";

/*
Definición: Delegación de Eventos
La delegación de eventos es una técnica en JavaScript que consiste en asignar un solo manejador de eventos a un elemento padre común en lugar de asignar manejadores a múltiples elementos hijos individuales.

Cómo funciona:
El evento se propaga (burbujea) desde el elemento hijo donde ocurrió el evento hasta sus elementos padres.
El manejador asignado al elemento padre detecta qué hijo originó el evento usando propiedades como event.target.
Esto permite manejar eventos de muchos elementos hijos con un solo listener, mejorando eficiencia y facilitando el manejo dinámico.

Ventajas:
Menos listeners: se reduce la cantidad de manejadores en el DOM, mejorando rendimiento.
Funciona con elementos dinámicos: si se agregan hijos nuevos al DOM, el listener del padre los maneja sin necesidad de asignar nuevos eventos.
Código más simple y mantenible
Resumen rápido:
document.addEventListener("click", ...) usa delegación de eventos: escucha en todo el documento y filtra por selector.
e.target.matches(selector) verifica si el elemento clickeado cumple con el selector dado.
e.preventDefault() cancela la acción predeterminada (como abrir un link).
e.stopPropagation() (comentado) detendría la propagación del evento hacia padres.
La función flujoEventos muestra en consola qué elemento originó el click.
*/

    `Hola te saluda ${this} el click lo originó ${e.target.className}`
  );
  // e.stopPropagation(); // Detiene la propagación del evento (comentado)
}

document.addEventListener("click", (e) => {

¿Qué es el BOM?

Leer explicación

El BOM (Browser Object Model) es un conjunto de objetos que permiten interactuar con el navegador sin depender directamente del contenido HTML. A diferencia del DOM, que se centra en la estructura y contenido del documento, el BOM nos da control sobre aspectos del navegador mismo.

Algunos de los aspectos que podemos manejar con el BOM incluyen:

  • Tamaño de ventana: controlar o consultar el ancho y alto del navegador.
  • Posición de la ventana: determinar dónde está ubicada la ventana en la pantalla.
  • Scroll: manejar el desplazamiento vertical u horizontal de la página.
  • Eventos del navegador: como load (cuando la página carga), resize (cuando cambia el tamaño de la ventana) o scroll (cuando se desplaza el contenido).
  • Acceso a objetos globales: como window, navigator, location, history y otros que permiten obtener información o controlar el comportamiento del navegador.

Resumen: El BOM es clave cuando necesitamos interactuar con el navegador mismo, más allá del documento HTML. Nos permite mejorar la experiencia del usuario, reaccionar a cambios de tamaño, controlar ventanas emergentes, y acceder a información del entorno donde se ejecuta nuestra aplicación.

// Muestra el objeto de geolocalización (permite acceder a ubicación)
console.log(navigator.geolocation);

// Muestra acceso a dispositivos multimedia (micrófono, cámara, etc.)
console.log(navigator.mediaDevices);

// Muestra los tipos MIME soportados por el navegador
console.log(navigator.mimeTypes);

// Muestra si el navegador está conectado a internet
console.log(navigator.onLine);

// Muestra información sobre el service worker si está registrado
console.log(navigator.serviceWorker);

// Muestra acceso al almacenamiento (caché, persistencia)
console.log(navigator.storage);

// Muestra acceso a dispositivos USB conectados (si es compatible)
console.log(navigator.usb);

// Muestra el user agent (información del navegador, versión, sistema operativo, etc.)
console.log(navigator.userAgent);
