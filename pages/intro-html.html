1. Estructura Básica de un Documento HTML

Leer explicación

Todo documento HTML debe tener una estructura básica que incluye la declaración DOCTYPE, las etiquetas html, head y body. Esta es la base de cualquier página web.

Ejemplo Práctico: Mi Página Personal

            
      <!-- La declaración DOCTYPE le dice al navegador que use HTML5 -->
      <!DOCTYPE html>

      <!-- La etiqueta html es el contenedor principal de todo el documento -->
      <!-- El atributo lang="es" indica que el idioma del contenido es español -->
      <html lang="es">

      <!-- El head contiene metadatos e información que no se muestra en la página -->
      <head>
        <!-- Charset UTF-8 permite mostrar caracteres especiales como ñ, á, é -->
        <meta charset="UTF-8">
        
        <!-- Viewport hace que la página sea responsive en dispositivos móviles -->
        <meta name="viewport" content="width=device-width, initial-scale=1.0">
        
        <!-- El título aparece en la pestaña del navegador -->
        <title>Mi Página Personal - Juan Pérez</title>
        
        <!-- Descripción para motores de búsqueda -->
        <meta name="description" content="Bienvenido a mi página personal">
      </head>

      <!-- El body contiene todo el contenido visible de la página -->
      <body>
        <!-- Encabezado principal de la página (solo debe haber uno por página) -->
        <h1>¡Hola! Soy Juan Pérez</h1>
        
        <!-- Párrafo con texto de presentación -->
        <p>Bienvenido a mi sitio web personal.</p>
        
        <!-- Subtítulo de nivel 2 -->
        <h2>Sobre mí</h2>
        
        <!-- Lista no ordenada de intereses -->
        <ul>
          <!-- Cada li es un elemento de la lista -->
          <li>Me gusta programar</li>
          <li>Disfruto aprender nuevas tecnologías</li>
          <li>Soy de Argentina</li>
        </ul>
        
        <!-- Enlace a otra página -->
        <p>
          <a href="contacto.html">Contáctame</a>
        </p>
      </body>

      <!-- Cierre de la etiqueta html -->
      </html>

¿Cómo se vería en el navegador?

  • Me gusta programar
  • Disfruto aprender nuevas tecnologías
  • Soy de Argentina

2. Encabezados (h1 - h6)

Leer explicación

Los encabezados van de <h1> (más importante) a <h6> (menos importante). Solo debe haber un <h1> por página y representan la jerarquía del contenido.

Ejemplo Práctico: Estructura de un Blog

            
      <!-- h1 es el título principal de la página (solo uno por página) -->
      <h1>Mi Blog de Programación</h1>

      <!-- h2 para títulos de artículos o secciones principales -->
      <h2>Artículo: Aprendiendo HTML desde Cero</h2>

      <!-- h3 para subsecciones dentro del artículo -->
      <h3>¿Qué es HTML?</h3>
      <p>HTML es el lenguaje de marcado...</p>

      <h3>Estructura Básica</h3>
      <p>Todo documento HTML necesita...</p>

      <!-- h4 para temas específicos dentro de las subsecciones -->
      <h4>Etiquetas Esenciales</h4>
      <p>Las etiquetas más usadas son...</p>

      <!-- h5 para detalles menores -->
      <h5>Nota Importante</h5>
      <p>Recuerda siempre cerrar las etiquetas...</p>

      <!-- h6 es el nivel más bajo (raramente usado) -->
      <h6>Dato Adicional</h6>
      <p>Los navegadores modernos...</p>

3. Párrafos y Saltos de Línea

Leer explicación

La etiqueta <p> crea párrafos con espaciado automático. <br> crea un salto de línea simple sin espacio adicional. La etiqueta <hr> crea una línea horizontal para separar contenido.

Ejemplo Práctico: Dirección Postal

            
      <!-- Párrafo simple con texto -->
      <p>Bienvenido a nuestra tienda online de tecnología.</p>

      <!-- Párrafo con saltos de línea usando br -->
      <!-- br es útil para direcciones, poemas o donde necesitas saltos sin espacio -->
      <p>
        Dirección de envío:<br>
        Juan Pérez<br>
        Calle San Martín 123<br>
        Jardín América, Misiones<br>
        Argentina
      </p>

      <!-- Otro párrafo independiente con espaciado automático -->
      <p>Hacemos envíos a todo el país.</p>

      <!-- hr crea una línea horizontal para separar secciones -->
      <hr>

      <!-- Nueva sección después de la línea separadora -->
      <p>
        Horario de atención:<br>
        Lunes a Viernes: 9:00 - 18:00<br>
        Sábados: 9:00 - 13:00
      </p>

4. Enlaces (Links)

Leer explicación

Los enlaces se crean con la etiqueta <a> y el atributo href. Pueden apuntar a páginas externas, internas o secciones de la misma página. Son fundamentales para la navegación web.

Ejemplo Práctico: Página de Contacto

            
      <h2>Contacto</h2>

      <!-- Enlace externo a otro sitio web -->
      <!-- href contiene la URL completa con https:// -->
      <p>
        Visita nuestro <a href="https://www.facebook.com/mitienda">Facebook</a>
      </p>

      <!-- Enlace interno a otra página del mismo sitio -->
      <!-- Solo necesita el nombre del archivo -->
      <p>
        Ver nuestros <a href="productos.html">Productos</a>
      </p>

      <!-- Enlace a una sección específica de la misma página -->
      <!-- El # indica que es un ancla dentro de la página -->
      <p>
        <a href="#horarios">Ver horarios de atención</a>
      </p>

      <!-- Enlace de email - abre el programa de correo -->
      <!-- mailto: seguido de la dirección de email -->
      <p>
        Email: <a href="mailto:contacto@mitienda.com">contacto@mitienda.com</a>
      </p>

      <!-- Enlace de teléfono - en móviles permite llamar directamente -->
      <!-- tel: seguido del número (con código de área) -->
      <p>
        Teléfono: <a href="tel:+543764123456">(3764) 123-456</a>
      </p>

      <!-- Enlace que se abre en nueva pestaña -->
      <!-- target="_blank" abre en nueva ventana/pestaña -->
      <!-- rel="noopener" es por seguridad cuando usas target="_blank" -->
      <p>
        <a href="https://www.google.com/maps" target="_blank" rel="noopener">
          Ver ubicación en Google Maps
        </a>
      </p>

      <!-- Enlace para descargar un archivo -->
      <!-- download sugiere descargar en vez de abrir -->
      <p>
        <a href="catalogo.pdf" download>Descargar catálogo PDF</a>
      </p>

      <!-- Sección de destino para el enlace de ancla -->
      <!-- El id debe coincidir con el href del enlace (sin el #) -->
      <h3 id="horarios">Horarios de Atención</h3>
      <p>Lunes a Viernes: 9:00 - 18:00</p>
      <p>Sábados: 9:00 - 13:00</p>

5. Imágenes

Leer explicación

La etiqueta <img> es auto-cerrada y requiere el atributo src (fuente de la imagen). El atributo alt es importante para accesibilidad y SEO, describe la imagen para personas con discapacidad visual.

Ejemplo Práctico: Galería de Productos

            
      <h2>Nuestros Productos</h2>

      <!-- Imagen básica -->
      <!-- src: ruta del archivo de imagen -->
      <!-- alt: descripción de la imagen (importante para accesibilidad) -->
      <img src="laptop.jpg" alt="Laptop HP Pavilion de 15 pulgadas">

      <!-- Imagen con tamaño específico -->
      <!-- width y height definen el ancho y alto en píxeles -->
      <img src="mouse.jpg" alt="Mouse inalámbrico Logitech" width="300" height="200">

      <!-- Imagen desde una URL externa -->
      <!-- src puede ser una URL completa de internet -->
      <img src="https://ejemplo.com/imagenes/teclado.jpg" alt="Teclado mecánico RGB">

      <!-- Figure y figcaption para imágenes con pie de foto -->
      <!-- figure agrupa la imagen con su descripción -->
      <figure>
        <!-- La imagen dentro del figure -->
        <img src="grafico-ventas.jpg" alt="Gráfico mostrando aumento de ventas" width="500">
        <!-- figcaption es el pie de foto o descripción -->
        <figcaption>Ventas del primer trimestre 2025 - Aumento del 35%</figcaption>
      </figure>

      <!-- Imagen como enlace clickeable -->
      <!-- Envolvemos la imagen con una etiqueta a -->
      <a href="producto-detalle.html">
        <img src="auriculares.jpg" alt="Auriculares Sony WH-1000XM4" width="250">
      </a>
      <p>Haz click en la imagen para ver más detalles</p>

      <!-- Imagen responsive que se adapta al tamaño de pantalla -->
      <!-- style="max-width: 100%" hace que nunca sea más ancha que su contenedor -->
      <!-- height="auto" mantiene las proporciones -->
      <img src="banner.jpg" alt="Banner de ofertas especiales" 
          style="max-width: 100%; height: auto;">

6. Listas

Leer explicación

Hay tres tipos de listas: <ul> (desordenada con viñetas), <ol> (ordenada con números) y <dl> (de definición para términos y descripciones).

Ejemplo Práctico: Lista de Compras y Receta

      <!-- Lista desordenada (ul = unordered list) -->
      <!-- Se usa cuando el orden NO es importante -->
      <!-- Muestra viñetas (bullets) por defecto -->
      <h3>Lista de Compras</h3>
      <ul>
        <!-- li = list item (elemento de lista) -->
        <li>Leche</li>
        <li>Pan</li>
        <li>Huevos</li>
        <li>Manteca</li>
      </ul>

      <!-- Lista ordenada (ol = ordered list) -->
      <!-- Se usa cuando el orden SÍ es importante -->
      <!-- Muestra números automáticamente -->
      <h3>Receta de Panqueques</h3>
      <ol>
        <li>Batir los huevos en un bowl</li>
        <li>Agregar la leche y mezclar</li>
        <li>Añadir la harina poco a poco</li>
        <li>Calentar la sartén con manteca</li>
        <li>Cocinar hasta que dore</li>
      </ol>

      <!-- Lista de definición (dl = definition list) -->
      <!-- Se usa para términos y sus definiciones -->
      <h3>Glosario de Programación</h3>
      <dl>
        <!-- dt = definition term (término) -->
        <dt>HTML</dt>
        <!-- dd = definition description (descripción) -->
        <dd>Lenguaje de marcado para estructurar páginas web</dd>
        
        <dt>CSS</dt>
        <dd>Hojas de estilo para diseñar y dar formato visual</dd>
        
        <dt>JavaScript</dt>
        <dd>Lenguaje de programación para interactividad</dd>
      </dl>

      <!-- Lista anidada (lista dentro de otra lista) -->
      <h3>Cursos Disponibles</h3>
      <ul>
        <li>Desarrollo Web
          <!-- Lista interna con sus propios elementos -->
          <ul>
            <li>HTML Básico</li>
            <li>CSS Avanzado</li>
            <li>JavaScript</li>
          </ul>
        </li>
        <li>Diseño Gráfico
          <ul>
            <li>Photoshop</li>
            <li>Illustrator</li>
          </ul>
        </li>
      </ul>

7. Formato de Texto

Leer explicación

HTML ofrece etiquetas para dar formato al texto: negrita, cursiva, subrayado, resaltado, etc. Algunas tienen significado semántico y otras son solo visuales.

Ejemplo Práctico: Artículo con Formatos

      <h2>Guía de HTML5</h2>

      <!-- strong: texto importante (negrita con significado) -->
      <!-- Los lectores de pantalla enfatizan este contenido -->
      <p>
        <strong>Importante:</strong> HTML5 es la última versión de HTML.
      </p>

      <!-- b: negrita visual sin significado especial -->
      <p>
        <b>Nota:</b> Usa siempre etiquetas semánticas.
      </p>

      <!-- em: énfasis (cursiva con significado) -->
      <!-- Cambia el significado de la oración -->
      <p>
        <em>Realmente</em> necesitas aprender HTML.
      </p>

      <!-- i: cursiva visual (sin énfasis especial) -->
      <!-- Útil para términos técnicos o palabras extranjeras -->
      <p>
        El término <i>responsive design</i> significa diseño adaptable.
      </p>

      <!-- u: texto subrayado -->
      <p>
        <u>Advertencia:</u> Guarda tu trabajo frecuentemente.
      </p>

      <!-- s o del: texto tachado (eliminado) -->
      <p>
        Precio: <s>$500</s> ahora $350
      </p>

      <!-- mark: texto resaltado como con marcador -->
      <p>
        Busca la palabra <mark>HTML</mark> en el documento.
      </p>

      <!-- small: texto más pequeño (letra chica) -->
      <p>
        Oferta válida hasta fin de mes. <small>Sujeto a disponibilidad.</small>
      </p>

      <!-- sup: superíndice (texto arriba) -->
      <p>
        La fórmula del agua es H<sub>2</sub>O y E=mc<sup>2</sup>
      </p>

      <!-- Combinando múltiples formatos -->
      <p>
        <strong><em>Muy importante:</em></strong> Siempre cierra tus etiquetas.
      </p>

8. Div y Span

Leer explicación

<div> es un contenedor de bloque para agrupar elementos (ocupa todo el ancho). <span> es un contenedor en línea para aplicar estilos a partes específicas de texto (solo ocupa el espacio necesario).

Ejemplo Práctico: Tarjeta de Producto

      <!-- div es un contenedor de bloque -->
      <!-- Se usa para agrupar y organizar secciones -->
      <!-- Cada div empieza en una nueva línea -->
      <div style="border: 1px solid #ccc; padding: 20px; width: 300px;">
        <!-- Encabezado de la tarjeta -->
        <h3>Laptop HP Pavilion</h3>
        
        <!-- Sección de precio -->
        <div style="background: #f0f0f0; padding: 10px; margin: 10px 0;">
          <p>Precio: <strong>$850</strong></p>
        </div>
        
        <!-- Descripción con span para resaltar palabras -->
        <!-- span es en línea: NO rompe el flujo del texto -->
        <p>
          Procesador <span style="color: blue; font-weight: bold;">Intel i5</span>, 
          memoria <span style="color: green; font-weight: bold;">8GB RAM</span>, 
          disco <span style="color: red; font-weight: bold;">256GB SSD</span>
        </p>
        
        <!-- Sección de acciones -->
        <div style="text-align: center; margin-top: 15px;">
          <button>Comprar Ahora</button>
        </div>
      </div>

      <!-- Ejemplo de span vs div -->
      <h3>Diferencia entre div y span</h3>

      <!-- Con div: cada elemento en nueva línea (bloque) -->
      <div>Elemento 1</div>
      <div>Elemento 2</div>
      <div>Elemento 3</div>

      <!-- Con span: todo en la misma línea (en línea) -->
      <p>
        <span>Elemento 1</span>
        <span>Elemento 2</span>
        <span>Elemento 3</span>
      </p>

9. Tablas

Leer explicación

Las tablas se crean con <table> y contienen <thead> (encabezado), <tbody> (cuerpo) y <tfoot> (pie). Cada fila es <tr> y cada celda <td> o <th>.

Ejemplo Práctico: Lista de Estudiantes

            
<!-- table: contenedor principal de la tabla -->
<!-- border="1" agrega bordes visibles -->
<table border="1">

<!-- thead: sección de encabezado de la tabla -->
<thead>
<!-- tr: table row (fila de la tabla) -->
<tr>
<!-- th: table header (celda de encabezado, en negrita) -->
<th>Nombre</th>
<th>Edad</th>
<th>Ciudad</th>
<th>Promedio</th>
</tr>
</thead>

<!-- tbody: sección del cuerpo con los datos -->
<tbody>
<!-- Primera fila de datos -->
<tr>
<!-- td: table data (celda de datos) -->
<td>Juan Pérez</td>
<td>25</td>
<td>Posadas</td>
<td>8.5</td>
</tr>

<!-- Segunda fila de datos -->
<tr>
<td>María González</td>
<td>30</td>
<td>Buenos Aires</td>
<td>9.2</td>
</tr>

<!-- Tercera fila de datos -->
<tr>
<td>Carlos López</td>
<td>28</td>
<td>Jardín América</td>
<td>7.8</td>
</tr>
</tbody>

<!-- tfoot: pie de tabla para totales o resumen -->
<tfoot>
<tr>
<!-- colspan="3" hace que esta celda ocupe 3 columnas -->
<td colspan="3"><strong>Promedio General</strong></td>
<td><strong>8.5</strong></td>
</tr>
</tfoot>
</table>

10. Formularios Básicos

Leer explicación

Los formularios recogen información del usuario. Incluyen diferentes tipos de inputs y botones de envío.

Ejemplo Práctico: Formulario de Contacto

            
<!-- form: contenedor del formulario -->
<!-- action: URL donde se envían los datos -->
<!-- method: POST (envía datos ocultos) o GET (visible en URL) -->
<form action="/procesar" method="POST">

<!-- label: etiqueta descriptiva del input -->
<!-- for debe coincidir con el id del input -->
<label for="nombre">Nombre:</label>
<!-- type="text": campo de texto normal -->
<!-- required: campo obligatorio -->
<input type="text" id="nombre" name="nombre" required>
<br><br>

<label for="email">Email:</label>
<!-- type="email": valida formato de email -->
<input type="email" id="email" name="email" required>
<br><br>

<label for="password">Contraseña:</label>
<!-- type="password": oculta el texto con asteriscos -->
<input type="password" id="password" name="password" required>
<br><br>

<label for="mensaje">Mensaje:</label>
<!-- textarea: área de texto para mensajes largos -->
<textarea id="mensaje" name="mensaje" rows="4" cols="30"></textarea>
<br><br>

<!-- button type="submit": envía el formulario -->
<button type="submit">Enviar</button>
</form>

11. Tipos de Inputs

Leer explicación

<input type="number" min="0" max="100" placeholder="Edad">

<!-- type="date": selector de fecha -->
<input type="date">
<br><br>

<!-- type="time": selector de hora -->
<input type="time">
<br><br>

<!-- type="color": selector de color -->
<input type="color">
<br><br>

<!-- type="range": control deslizante -->
<input type="range" min="0" max="100">
<br><br>

<!-- type="file": selector de archivos -->
<input type="file">
<br><br>

<!-- type="checkbox": casillas (múltiples opciones) -->
<input type="checkbox" id="deportes">

<br>
<input type="checkbox" id="musica">
<label for="musica">Música</label>

</select>

12. Etiquetas Semánticas

Leer explicación

HTML5 introdujo etiquetas semánticas que dan significado al contenido: <header>, <nav>, <main>, <article>, <section>, <aside>, <footer>.

Ejemplo Práctico: Estructura de un Blog

            
<!-- header: encabezado del sitio (logo, título, menú) -->
<header>
<!-- Título principal del sitio -->
<h1>Mi Blog de Tecnología</h1>

<!-- nav: sección de navegación (menú) -->
<nav>
<ul>

13. Audio y Video

Leer explicación

HTML5 permite incrustar audio y video nativamente sin plugins externos. Se pueden incluir controles y especificar múltiples fuentes.

Ejemplo Práctico: Reproductor Multimedia

            
<!-- video: elemento para videos -->
<!-- width y height: dimensiones del reproductor -->
<!-- controls: muestra botones de play, pausa, volumen -->
<video width="640" height="360" controls>
<!-- source: especifica el archivo de video -->
<!-- type: tipo de archivo (mp4, webm, ogg) -->
<source src="video.mp4" type="video/mp4">
<source src="video.webm" type="video/webm">
<!-- Texto alternativo si el navegador no soporta video -->
Tu navegador no soporta video HTML5.
</video>

<!-- audio: elemento para archivos de audio -->
<!-- controls: muestra los controles de reproducción -->
<audio controls>
<!-- Múltiples fuentes para compatibilidad -->
<source src="audio.mp3" type="audio/mpeg">
<source src="audio.ogg" type="audio/ogg">
Tu navegador no soporta audio HTML5.
</audio>

<!-- Video con más atributos -->
<!-- autoplay: inicia automáticamente -->
<!-- loop: se repite al finalizar -->
<!-- muted: sin sonido (necesario para autoplay) -->
<video width="400" controls autoplay loop muted>
<source src="video.mp4" type="video/mp4">
</video>

14. iFrame (Marcos Embebidos)

Leer explicación

Los iframes permiten incrustar otra página HTML dentro de la actual. Útil para mapas, videos de YouTube, o contenido de terceros.

Ejemplo Práctico: Incrustar Contenido Externo

            
<!-- iframe: marco embebido para contenido externo -->
<!-- src: URL de la página a incrustar -->
<!-- width y height: dimensiones del iframe -->
<!-- title: descripción para accesibilidad -->
<iframe 
src="https://www.openstreetmap.org/export/embed.html"
width="600"
height="400"
title="Mapa de ejemplo"
></iframe>

<!-- Incrustar video de YouTube -->
<!-- allowfullscreen: permite ver en pantalla completa -->
<iframe 
src="https://www.youtube.com/embed/dQw4w9WgXcQ"
width="560"
height="315"
title="Video de YouTube"
allowfullscreen
></iframe>

<!-- Incrustar Google Maps -->
<iframe 
src="https://www.google.com/maps/embed?pb=..."
width="600"
height="450"
style="border:0;"
allowfullscreen=""
loading="lazy"
></iframe>

15. Meta Tags

Leer explicación

Las meta tags proporcionan información sobre la página para navegadores y motores de búsqueda. Son esenciales para SEO y compartir en redes sociales.

Ejemplo Práctico: Meta Tags Completas

            
<!DOCTYPE html>
<html lang="es">
<head>
<!-- charset: define la codificación de caracteres (UTF-8 es estándar) -->
<meta charset="UTF-8">

<!-- viewport: hace la página responsive en móviles -->
<!-- width=device-width: ancho igual al dispositivo -->
<!-- initial-scale=1.0: zoom inicial al 100% -->
<meta name="viewport" content="width=device-width, initial-scale=1.0">

<!-- Título que aparece en la pestaña del navegador -->
<title>Mi Blog de Tecnología - Tutoriales y Noticias</title>

<!-- description: resumen de la página (aparece en Google) -->
<!-- Importante para SEO (máximo 155 caracteres) -->
<meta name="description" content="Aprende HTML, CSS y JavaScript con tutoriales prácticos y ejemplos reales">

<!-- keywords: palabras clave (menos importante hoy en día) -->
<meta name="keywords" content="HTML, CSS, JavaScript, tutorial, programación">

<!-- author: autor de la página -->
<meta name="author" content="Juan Pérez">

<!-- robots: indica a los motores de búsqueda qué hacer -->
<!-- index: indexar la página, follow: seguir los enlaces -->
<meta name="robots" content="index, follow">

<!-- Open Graph: para cuando se comparte en redes sociales -->
<!-- og:title: título que aparece en Facebook, Twitter, etc -->
<meta property="og:title" content="Mi Blog de Tecnología">

<!-- og:description: descripción para redes sociales -->
<meta property="og:description" content="Tutoriales de programación web">

<!-- og:image: imagen que se muestra al compartir -->
<meta property="og:image" content="https://miblog.com/imagen-destacada.jpg">

<!-- og:url: URL de la página -->
<meta property="og:url" content="https://miblog.com">

<!-- og:type: tipo de contenido -->
<meta property="og:type" content="website">

<!-- Twitter Card para Twitter específicamente -->
<meta name="twitter:card" content="summary_large_image">
<meta name="twitter:title" content="Mi Blog de Tecnología">
<meta name="twitter:description" content="Tutoriales de programación web">
<meta name="twitter:image" content="https://miblog.com/imagen-destacada.jpg">
</head>
<body>
<h1>Bienvenido a Mi Blog</h1>
<p>Contenido de la página...</p>
</body>
</html>

16. Enlaces a CSS y JavaScript

Leer explicación

Para conectar archivos CSS y JavaScript externos, se usan las etiquetas <link> y <script> dentro del <head> o antes de cerrar </body>.

Ejemplo Práctico: Conectar Archivos Externos

            
<!DOCTYPE html>
<html lang="es">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Mi Página con Estilos y Scripts</title>

<!-- link: enlaza archivos CSS externos -->
<!-- rel="stylesheet": indica que es una hoja de estilos -->
<!-- href: ruta del archivo CSS -->
<link rel="stylesheet" href="estilos.css">

<!-- Enlazar múltiples archivos CSS -->
<link rel="stylesheet" href="css/normalize.css">
<link rel="stylesheet" href="css/main.css">

<!-- icon: define el favicon (icono de la pestaña) -->
<link rel="icon" href="favicon.ico" type="image/x-icon">

<!-- Enlazar fuentes de Google Fonts -->
<link rel="preconnect" href="https://fonts.googleapis.com">
<link href="https://fonts.googleapis.com/css2?family=Roboto&display=swap" rel="stylesheet">

<!-- Script en el head (menos común, solo si es necesario antes del body) -->
<script src="configuracion.js"></script>
</head>

<body>
<!-- Contenido de la página -->
<h1>Mi Página Web</h1>
<p>Contenido con estilos CSS aplicados</p>
<button id="miBoton">Click aquí</button>

<!-- script: enlaza archivos JavaScript -->
<!-- Se coloca antes de cerrar body para que cargue después del HTML -->
<!-- src: ruta del archivo JavaScript -->
<script src="script.js"></script>

<!-- Enlazar múltiples archivos JS -->
<script src="js/funciones.js"></script>
<script src="js/animaciones.js"></script>

<!-- defer: carga el script después del HTML (alternativa moderna) -->
<script src="app.js" defer></script>

<!-- JavaScript en línea (dentro del HTML) -->
<script>
console.log("Hola desde JavaScript");
</script>
</body>
</html>

💡 Buenas prácticas:

  • CSS siempre en el <head>
  • JavaScript al final del <body>
  • Usa archivos externos (no estilos inline)
  • Minifica archivos en producción

17. Data Attributes (Atributos de Datos)

Leer explicación

Los atributos data-* permiten almacenar información personalizada en elementos HTML sin afectar la presentación. Son útiles para JavaScript y CSS, ya que facilitan el acceso a datos dinámicos.

Ejemplo Práctico: Almacenar Datos Personalizados

            
<!-- Contenedor con información personalizada de un usuario -->
<div 
  <!-- data-user-id: identifica al usuario -->
data-user-id="12345"
  <!-- data-role: define su rol o nivel de permisos -->
data-role="admin"
  <!-- data-created: guarda la fecha de creación -->
data-created="2025-01-15"
>
Usuario Admin
</div>

<!-- Botón con datos personalizados -->
<button 
  <!-- data-action: define la acción a ejecutar -->
data-action="delete" 
  <!-- data-id: identifica el elemento asociado -->
data-id="67890">
Eliminar
</button>

<!-- Acceso con JavaScript: element.dataset.userId -->

¿Cómo se vería en el navegador?

Usuario Admin

18. ARIA (Accesibilidad)

Leer explicación

ARIA (Accessible Rich Internet Applications) proporciona atributos que mejoran la accesibilidad de las aplicaciones web, facilitando su uso por personas con discapacidades.

Ejemplo Práctico: Navegación Accesible

            
<!-- Menú de navegación principal accesible -->
<nav aria-label="Navegación principal">
  <ul role="menubar">
    <li role="none">
      <a href="#" role="menuitem">Inicio</a>
    </li>
  </ul>
</nav>

<!-- Botón con etiqueta accesible y estado -->
<button 
  <!-- aria-label: texto alternativo leído por lectores de pantalla -->
aria-label="Cerrar ventana" 
  <!-- aria-pressed: indica si el botón está activo o no -->
aria-pressed="false">
X
</button>

<!-- Mensaje dinámico accesible -->
<div 
  <!-- role="alert": indica contenido importante -->
role="alert" 
  <!-- aria-live="polite": lector de pantalla lo anuncia sin interrumpir -->
aria-live="polite">
Mensaje importante
</div>

<!-- Campo de texto obligatorio y validado -->
<input 
type="text" 
  <!-- aria-required: indica que es obligatorio -->
aria-required="true" 
  <!-- aria-invalid: marca si tiene error -->
aria-invalid="false">

19. Picture (Imágenes Responsive)

Leer explicación

El elemento <picture> permite mostrar diferentes imágenes según el tamaño de pantalla o el formato compatible del navegador, optimizando la carga y adaptabilidad del contenido visual.

Ejemplo Práctico: Imágenes Adaptables

            
<!-- Muestra diferentes imágenes según el ancho de pantalla -->
<picture>
  <!-- Imagen grande para pantallas grandes (>=1200px) -->
<source media="(min-width: 1200px)" srcset="imagen-grande.jpg">
  <!-- Imagen mediana para tablets o pantallas medianas -->
<source media="(min-width: 768px)" srcset="imagen-mediana.jpg">
  <!-- Imagen pequeña para celulares -->
<source media="(min-width: 320px)" srcset="imagen-pequena.jpg">
  <!-- Imagen por defecto si ninguna condición aplica -->
<img src="imagen-default.jpg" alt="Descripción">
</picture>

<!-- Ejemplo con formato WebP y fallback JPEG -->
<picture>
  <!-- Imagen WebP (más liviana si el navegador la soporta) -->
<source srcset="imagen.webp" type="image/webp">
  <!-- Fallback JPG si no soporta WebP -->
<source srcset="imagen.jpg" type="image/jpeg">
  <!-- Imagen final visible -->
<img src="imagen.jpg" alt="Descripción">
</picture>

20. Details y Summary (Acordeones)

Leer explicación

Las etiquetas <details> y <summary> crean elementos desplegables nativos sin necesidad de JavaScript. Son perfectas para construir acordeones o contenido colapsable. 

            
<!-- Contenedor desplegable nativo -->
<details>
<!-- Resumen visible, se puede hacer clic -->
<summary>Haz clic para ver más</summary>
<!-- Contenido que se oculta por defecto -->
<p>Este contenido está oculto por defecto.</p>
</details>

<details open> <!-- Se abre por defecto -->
<summary>Este está abierto por defecto</summary>
<p>Contenido visible.</p>
</details>

¿Cómo se vería en el navegador?

Haz clic para ver más

Este está abierto por defecto

21. Template (Plantillas HTML)

Leer explicación

La etiqueta <template> contiene HTML no renderizado hasta que se activa con JavaScript. Útil para crear componentes dinámicos sin duplicar código. 

            
<!-- Plantilla HTML oculta -->
<template id="mi-plantilla">
<!-- Contenedor interno de la plantilla -->
<div>
<h3>Título</h3> <!-- Título dentro de plantilla -->
<p>Contenido de la plantilla</p> <!-- Texto de la plantilla -->
</div>
</template>

<!-- Clonar la plantilla con JavaScript -->
const template = document.getElementById('mi-plantilla');
const clone = template.content.cloneNode(true);

¿Cómo se vería en el navegador?

La plantilla no se muestra hasta que se clona con JavaScript.

22. Dialog (Modales Nativos)

Leer explicación

La etiqueta <dialog> permite crear ventanas modales nativas sin librerías externas. Se controla con JavaScript usando .showModal() y .close(). 

            
<!-- Modal nativo -->
<dialog id="mi-modal">
<h2>Título del Modal</h2> <!-- Título del modal -->
<p>Contenido del modal.</p> <!-- Texto dentro del modal -->
<button onclick="this.closest('dialog').close()">Cerrar</button> <!-- Botón para cerrar modal -->
</dialog>

<button onclick="document.getElementById('mi-modal').showModal()">Abrir Modal</button>
<!-- Botón para abrir modal -->

23. Progress y Meter

Leer explicación

<progress> muestra el progreso de una tarea. <meter> representa una medición dentro de un rango, como nivel de batería o calificación. 

            
<!-- Barra de progreso completada -->
<progress value="70" max="100">70%</progress>

<!-- Barra de progreso indeterminada -->
<progress></progress>

<!-- Medidor con rango y valores óptimos -->
<meter value="6" min="0" max="10" low="3" high="7" optimum="8">6 de 10</meter>

¿Cómo se vería en el navegador?

70% 6 de 10
