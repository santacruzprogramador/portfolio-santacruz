¿Qué es Python?

Leer explicación

Python es un lenguaje de programación de alto nivel, interpretado y de propósito general. Fue creado por Guido van Rossum y lanzado por primera vez en 1991. Se destaca por su sintaxis sencilla y clara, ideal para principiantes, pero también muy poderoso y ampliamente usado por profesionales.

Característica de Python

Leer explicación

Python es un lenguaje de programación interpretado, lo que significa que no necesita ser compilado antes de ejecutarse. Esto facilita la escritura y prueba de código, ya que los desarrolladores pueden ver los resultados de sus cambios de inmediato.

  • Legibilidad: Python utiliza una sintaxis clara y concisa que facilita la lectura y comprensión del código. La indentación es obligatoria, lo que ayuda a mantener una estructura organizada.
  • Multiplataforma: Python es compatible con múltiples sistemas operativos, como Windows, macOS y Linux, lo que permite a los desarrolladores escribir código que funcione en diferentes entornos sin modificaciones significativas.
  • Bibliotecas y frameworks: Python cuenta con una amplia gama de bibliotecas y frameworks que facilitan el desarrollo de aplicaciones en diversas áreas, como ciencia de datos, desarrollo web, automatización, inteligencia artificial y más.
  • Comunidad activa: Python tiene una comunidad de desarrolladores muy activa que contribuye con recursos, tutoriales y soporte. Esto hace que sea fácil encontrar ayuda y aprender nuevas habilidades.
  • Versatilidad: Python se utiliza en una variedad de aplicaciones, desde scripts simples hasta aplicaciones web complejas y análisis de datos. Su versatilidad lo convierte en una opción popular para muchos tipos de proyectos.

¿Cuál es la diferencia entre tipado dinámico y estático?

Leer explicación
  • Tipado Dinámico (flexible): El tipo de una variable se decide en tiempo de ejecución. No necesitas declarar el tipo de la variable cuando la defines, y puede cambiar de tipo a lo largo del programa. Ejemplo: Python.
  • Tipado Estático (rígido ayuda evitar errores): El tipo de una variable se decide en tiempo de compilación. Debes especificar el tipo de la variable antes de usarla, y no puede cambiar durante la ejecución. Ejemplo: Java

# Finalmente, cambiamos 'variable' a una lista

print(f"El valor de 'variable' es {variable} y su tipo es {type(variable)}")

¿Qué son los paradigmas de programación?

Leer explicación

Los paradigmas de programación son enfoques o estilos de programación que definen cómo se estructura y organiza el código. Algunos de los paradigmas más comunes incluyen:

  • Programación Imperativa: Se centra en describir cómo se debe realizar una tarea mediante instrucciones secuenciales. Ejemplos: C, Python.
  • Programación Orientada a Objetos (POO): Organiza el código en "objetos" que contienen datos y métodos. Ejemplos: Java, C++, Python.
  • Programación Funcional: Se basa en funciones matemáticas y evita el estado mutable. Ejemplos: Haskell, Lisp, Python.
  • Programación Declarativa: Describe qué se quiere lograr sin especificar cómo hacerlo. Ejemplos: SQL, HTML.

¿Qué paradigma se usa en Python?

Leer explicación

Python es un lenguaje de programación multiparadigma, lo que significa que soporta varios paradigmas de programación. Los principales paradigmas que se pueden utilizar en Python son:

  • Programación Imperativa: Python permite escribir código de manera secuencial, utilizando variables, bucles y condicionales para controlar el flujo del programa.
  • Programación Orientada a Objetos (POO): Python tiene un fuerte soporte para la POO, permitiendo la creación de clases y objetos, encapsulación, herencia y polimorfismo.
  • Programación Funcional: Python incluye características de programación funcional, como funciones de primera clase, funciones lambda, y herramientas como map(), filter() y reduce().
  • Programación Declarativa: Aunque no es su enfoque principal, Python puede utilizarse para programación declarativa en ciertos contextos, como en frameworks web o bibliotecas específicas.

¿Cuál es la diferencia entre interpretado y compilado?

Leer explicación

La diferencia principal entre lenguajes interpretados y compilados radica en cómo se ejecuta el código:

  • Lenguajes Compilados: El código fuente se traduce completamente a código máquina mediante un compilador antes de la ejecución. Esto genera un archivo ejecutable que puede ser ejecutado directamente por el sistema operativo. Ejemplos: C, C++.
  • Lenguajes Interpretados: El código fuente se ejecuta línea por línea mediante un intérprete en tiempo de ejecución. No se genera un archivo ejecutable independiente, y el código puede ser modificado y probado rápidamente. Ejemplos: Python, JavaScript.

¿Python es interpretado y dinámico?

Leer explicación

Python es un lenguaje de programación interpretado, lo que significa que su código fuente se ejecuta directamente por un intérprete en tiempo de ejecución, sin necesidad de ser compilado previamente a código máquina. El intérprete de Python lee y ejecuta el código línea por línea, lo que facilita la escritura, prueba y depuración del código. Esta característica hace que Python sea muy flexible y adecuado para una amplia variedad de aplicaciones, desde scripts simples hasta aplicaciones web complejas y análisis de datos.

Operadores

Leer explicación

Los operadores son símbolos o palabras clave que realizan operaciones específicas en uno o más operandos (valores o variables).

Los operadores son:

  • Aritméticos:
    • + : Suma → añade dos valores
    • - : Resta → resta un valor de otro
    • * : Multiplicación → multiplica dos valores
    • / : División → divide un valor entre otro, devuelve decimal
    • // : División entera → divide y devuelve solo la parte entera
    • % : Módulo → devuelve el resto de una división
    • ** : Potencia → eleva un valor a la potencia de otro
  • Comparación:
    • == : Igual que → True si los valores son iguales
    • != : Distinto que → True si los valores son diferentes
    • > : Mayor que → True si el primero es mayor
    • < : Menor que → True si el primero es menor
    • >= : Mayor o igual → True si el primero es mayor o igual
    • <= : Menor o igual → True si el primero es menor o igual
  • Asignación:
    • = : Asigna un valor a una variable
    • += : Suma y asigna → x += 3 equivale a x = x + 3
    • -= : Resta y asigna → x -= 2 equivale a x = x - 2
    • *= : Multiplica y asigna → x *= 2 equivale a x = x * 2
    • /= : Divide y asigna → x /= 4 equivale a x = x / 4
    • //= : División entera y asigna → x //= 3
    • %= : Módulo y asigna → x %= 3
    • **= : Potencia y asigna → x **= 3
  • Booleanos:
    • True : Valor verdadero
    • False : Valor falso
  • Lógicos:
    • and : Verdadero si ambas condiciones son verdaderas
    • or : Verdadero si al menos una condición es verdadera
    • not : Niega la condición

Condicionales

Leer explicación

Las condicionales permiten que el programa tome decisiones. Se usa la palabra clave if, seguida opcionalmente de elif y else. 

            
# Ejemplo básico de condicional
edad = 18
if edad >= 18:
    mensaje = "Eres mayor de edad"
elif edad == 17:
    mensaje = "Casi eres mayor de edad"
else:
    mensaje = "Eres menor de edad"

# Comparación de números
numero = 5
if numero > 0:
    resultado = "Número positivo"
elif numero < 0:
    resultado = "Número negativo"
else:
    resultado = "Es cero"

# Condicionales con operadores lógicos
usuario = "admin"
clave = "1234"
if usuario == "admin" and clave == "1234":
    acceso = "Acceso concedido"
else:
    acceso = "Acceso denegado"

# Condicionales anidadas
nota = 85
if nota >= 60:
    if nota >= 90:
        evaluacion = "Excelente"
    else:
        evaluacion = "Aprobado"
else:
    evaluacion = "Reprobado"

Bucles

Leer explicación

Los bucles permiten ejecutar una serie de instrucciones varias veces. En Python tenemos for y while, y control de flujo con break y continue. 

            
# Bucle FOR sobre una lista
frutas = ["manzana", "banana", "pera"]
for fruta in frutas:
    resultado1 = fruta

# Bucle FOR con range()
for i in range(3):
    resultado2 = i

# Bucle WHILE
contador = 0
while contador < 3:
    resultado3 = contador
    contador += 1

# break → interrumpe el bucle
for num in range(10):
    if num == 5:
        break
    resultado4 = num

# continue → salta a la siguiente iteración
for num in range(5):
    if num == 2:
        continue
    resultado5 = num

# else con bucles → se ejecuta si no hubo break
for n in range(3):
    resultado6 = n
else:
    finalizado = "Bucle finalizado sin interrupciones"

Funciones

Leer explicación

Una función es un bloque de código reutilizable. Se define con def y puede recibir parámetros, retornar valores y contener funciones anidadas. 

            
# Función básica sin parámetros
def saludar():
    mensaje = "Hola, bienvenido"

# Función con un parámetro
def saludar_nombre(nombre):
    saludo = f"Hola, {nombre}"

# Función con varios parámetros
def sumar(a, b):
    resultado = a + b

# Función con valor de retorno
def multiplicar(x, y):
    return x * y

# Función con valor por defecto
def saludar_idioma(nombre, idioma="es"):
    if idioma == "es":
        saludo = f"Hola, {nombre}"
    elif idioma == "en":
        saludo = f"Hello, {nombre}"
    else:
        saludo = f"Saludos, {nombre}"

# Función que retorna múltiples valores
def operaciones(a, b):
    suma = a + b
    resta = a - b
    return suma, resta

# Función lambda (anónima, de una línea)
cuadrado = lambda n: n * n
doble = lambda n: n * 2

# Función dentro de otra función (anidada)
def operacion_compleja(x):
    def elevar_al_cuadrado(n):
        return n * n
    resultado = elevar_al_cuadrado(x)

Concatenación

Leer explicación

Convenciones de nombres

Leer explicación

Python sigue convenciones de nombres para mantener la coherencia en el código. Algunas de las más comunes son snake_case para variables, PascalCase para clases y UPPER_SNAKE_CASE para constantes. 

            
# snake_case → variables, funciones
nombre_variable = 10
def mi_funcion_ejemplo():
    pass

# PascalCase → clases
class MiClaseEjemplo:
    def metodo(self):
        pass

# UPPER_SNAKE_CASE → constantes
PI = 3.1416
MAX_INTENTOS = 5

# lowercase → módulos o archivos
# Ejemplo: miarchivo.py

# mixedCase (no recomendado)
miVariable = 20

# _variable → indica variable privada
class Ejemplo:
    def __init__(self):
        self._variable_privada = 10

# __variable → evita colisiones (name mangling)
class OtroEjemplo:
    def __init__(self):
        self.__variable_mangling = 5

# Métodos mágicos (dunder)
class Magia:
    def __init__(self):
        pass
    def __str__(self):
        return "Ejemplo de método mágico"

# Ejemplo de uso
class Persona:
    def __init__(self, nombre):
        self.nombre = nombre

p = Persona("Juan")
print(str(p))
